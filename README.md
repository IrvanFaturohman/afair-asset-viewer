# A FAIR Studio · Nusantara Kit Asset Viewer

Katalog 3D interaktif untuk usaha **3D Asset for Game Development** (A FAIR Studio), mata kuliah Kewirausahaan.
Semua model dibuat secara prosedural dengan [Three.js](https://threejs.org), tanpa file model eksternal.

**Demo:** https://irvanfaturohman.github.io/afair-asset-viewer/

## Isi paket (35 aset)

| Kategori | Aset |
|---|---|
| Environment Kit | Lapak Pasar Joglo, Rumah Panggung, Gapura Candi Bentar, Pos Ronda, Pagar Bambu Modular, Jalan Modular, Pohon Pisang, Pohon Kelapa, Rumpun Bambu, Batu & Semak, Demo Scene Desa Pasar |
| Karakter | Pedagang Pikulan, Petani, Prajurit Kerajaan, Penjual Jamu Gendong |
| Senjata | Keris Luk 7, Tombak, Golok, Tameng Dayak |
| Kendaraan | Gerobak Kayu, Becak, Perahu Jukung |
| Props | Keranjang, Kendi, Gentong, Petromaks, Obor, Karung, Lesung & Alu, Tampah Sayur, Meja & Lincak, Gong, Bedug, Angklung |
| Texture Pack | 9 material PBR (kayu, bata, batik kawung, anyaman, genteng, paving, bambu, tembok kapur, tanah) |

## Fitur viewer

- LOD0 / LOD1 / LOD2 dengan jumlah triangle tiap level
- Mode Shaded, Wireframe, dan Clay
- Collision mesh
- 3 varian warna (Kayu Jati, Bambu, Cat Warna)
- Penamaan file standar engine (`SM_`, `SK_`, `T_`)
- Render PNG dengan latar transparan
- Mode presentasi: auto-tour, navigasi ◀ ▶, layar penuh

## Shortcut

`←` `→` ganti aset · `1` `2` `3` LOD · `W` wireframe · `C` collision · `T` turntable · `P` auto-tour · `F` layar penuh

## Menjalankan lokal

Buka `index.html` langsung di browser (butuh internet untuk memuat Three.js dari CDN).
